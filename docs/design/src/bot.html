Stage 1 · Data

Case study: RiskLens

Before any signal, a bot needs prices it can trust. RiskLens loads daily closes, aligns every asset to the same dates, and drops any date where a price is missing instead of filling it in.

What to check

  • Dates are sorted and unique
  • High ≥ open and close; low ≤ both
  • No silent forward-fill across missing days
  • Splits and dividends: adjusted or not, written down
  • Source and download date recorded with the data

Excerpt (MIT, RiskLens)

# src/risklens/data.py, line 86
prices = close[tickers].dropna()

# line 237
return prices.astype(float).pct_change().dropna(how="all")

Rows with any missing close are dropped, not filled.

In this app, the same checks run when you import a CSV or load Kraken, Alpha Vantage or CoinGecko data in the Backtesting lab.
